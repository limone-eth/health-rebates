# Design files

`rebates.op` holds the design system (colors, type, buttons, ticket) and the first screens.

The screens in `rebates.op` show the earlier layout and the earlier titles. They do not show the wide ticket. We changed the layout in the code, and the owner reviewed it in the browser.

The reference for the screens is now the app, in `web/public/`. The tokens in `rebates.op` still match `web/public/styles.css`.

See [the layout record](../decisions/2026-11-04-screen-layout.md) and [the titles record](../decisions/2026-11-04-screen-titles.md).
